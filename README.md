# dopa-macbook

打鍵するたびに Mac 全体がクラブになる、メニューバー常駐の打鍵エフェクトアプリです。
どのアプリで文字を打っても、コンボ表示・星の粒・レーザー・ムービングライトが画面に重なり、100 コンボで FEVER TIME（4つ打ちの曲つき）に突入します。

## できること

- **コンボ**：打つたびにカーソル横へ `26 COMBO A` のように表示。2.5 秒手を止めると COMBO BREAK
  - ランクは C → B → A → S → SS → SSS
  - カーソル位置が取れないアプリ（Zed など）では、マウスのある画面のランダムな位置に出ます
- **節目の演出**：10 / 20 / 30 / 50 / 75 コンボでバナー（COMBO x10、ON FIRE x30 など）と花火
- **クラブ演出**：コンボが伸びるほど増える
  | コンボ | 演出 |
  |---|---|
  | 10〜 | ムービングライト、ミラーボールの反射光、画面の縁の光 |
  | 20〜 | 画面下からレーザー |
  | 30〜 | 上の両角からもレーザー、上から照らすスポットライト |
  | 50〜 | 打鍵ごとにレーザーの色が切り替わる |
- **FEVER TIME**：100 コンボで突入して 20 秒続く。FEVER 中に 50 コンボ伸ばすと延長
  - 140BPM の4つ打ちの曲（アプリ内で合成）がループで流れる
  - ビートに合わせて画面全体の明滅、レーザーの開閉、花火、衝撃波
  - 24 種類の煽り文字（脳汁ドバドバ!!、限界突破!!、INCREDIBLE!! など）が、同じものが続かないようランダムに叩きつけられる
- **単語への反応**：カーソル直前の文字を見て反応する
  | 単語 | 演出 |
  |---|---|
  | 完成・できた・done | SHIPPED! |
  | リリース・デプロイ・release | LAUNCH!! |
  | 好き・love | LOVE ♡ |
  | 最高・神・天才・優勝 | CRITICAL!! |
  | いいね・ナイス・nice | NICE! |
- **録画**：メニューから、マウスのある画面を音声付きで録画（100 連打のテストを流して `~/Movies` に mp4 で保存）

レーザーや花火などの重い演出は、負荷を抑えるためマウスのある画面にだけ出ます。

## 動作環境

- macOS 15 以降（録画機能が macOS 15 の API を使っています）
- Xcode のコマンドラインツール（`swiftc`）

## ビルドと起動

```sh
# 初回だけ：署名用の自己署名証明書をログインキーチェーンに作る（任意・おすすめ）
./setup-signing.sh

# ビルド（build/dopa-macbook.app ができる）
./build.sh

# 起動
open build/dopa-macbook.app
```

`setup-signing.sh` で作った証明書（「DopaPachinko Dev」）で署名すると、ビルドし直しても下の許可が外れません。
証明書がない場合は仮の署名になり、ビルドするたびに許可の取り直しが必要です。
不要になったら「キーチェーンアクセス」で「DopaPachinko Dev」を削除してください。

## 必要な許可

システム設定 →「プライバシーとセキュリティ」で dopa-macbook をオンにします。

| 許可 | 用途 |
|---|---|
| アクセシビリティ | どのアプリでの打鍵も検知する。カーソル位置と、カーソル直前の十数文字（単語への反応用）を読む |
| 画面収録とシステムオーディオ録音 | メニューからの録画を使うときだけ |

テスト演出（メニューの「テスト: …」）は、許可がなくても動きます。
パスワード入力欄では、macOS の仕様で反応しません。読んだ文字はアプリの中だけで使い、どこにも送りません。

## 使い方

メニューバーの「DOPA」から操作します。

| 項目 | 内容 |
|---|---|
| ドパガキモード（⌃⌥⌘P） | 全演出のオン・オフ。⌃⌥⌘P でどこからでも切り替えられる |
| サウンド | 効果音と FEVER の曲のオン・オフ |
| テスト: 30連打 / 100連打（FEVER） | 打鍵を再現して演出を確認する |
| テスト: 100連打を音声付きで録画 | 上のテストを録画して `~/Movies` に保存する |
| 終了 | アプリを終了する |

コマンドからも録画できます（設定がオフでも、このときだけ演出と音をオンにして録り、終わると終了します）。

```sh
open build/dopa-macbook.app --args --record-demo
```

## 調整

`main.swift` の冒頭にある `Tune` で変えられます。

| 値 | 既定 | 内容 |
|---|---|---|
| `comboTimeout` | 2.5 | この秒数手が止まると COMBO BREAK |
| `feverDuration` | 20.0 | FEVER TIME の長さ（秒） |

FEVER 中の言葉は `Dopa.shouts`、単語への反応は `Dopa.keywords` にあります。

## 注意

- 画面共有や録画中も演出はそのまま映ります。止めたいときは ⌃⌥⌘P
- FEVER 中の画面全体の明滅は、光過敏への配慮として1秒に3回未満（1拍に1回）に抑えています
